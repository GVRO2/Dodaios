# Domain Context — html-open-in-browser

## Glossary

- HTML link — any clickable reference in a thread's answer (a link, a file chip or a file name written as code) whose target is a local file ending in .html or .htm on the computer running Dodaios. NOT a page already drawn inside the answer, NOT a web link (an address on the web), which keeps opening as it does today.
- Opening preference — the person's remembered answer to how HTML links open: ask, rendered page, or source view. NOT the system's default application for HTML files, which Dodaios does not change.
- Person — someone using Dodaios on the computer where it runs, with a screen. NOT the remote viewer.
- Remote viewer — someone using Dodaios from a different device than the one it runs on, including any use of a server with no screen. NOT the person, whose browser Dodaios can open.
- Rendered page — the HTML file shown as a web page in a web browser, as when it is opened from its folder. NOT the static preview.
- Source view — the file's markup shown as text in the side panel. NOT a rendered form of the file.
- Static preview — the file drawn inside Dodaios without running its scripts. NOT the rendered page, which is the browser's full rendering.
